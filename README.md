# ทายเพลง — Guess Music

เกมทายเพลงเล่นหลายคนพร้อมกัน เข้าห้องด้วยรหัส 4 ตัวอักษร ฟังคลิปเพลงเดียวกัน เลือกจาก 4 ตัวเลือก แล้วเฉลยพร้อมกันทั้งห้อง

UI เป็นแนว Swiss Design ขาว/ดำ + แดงสีเดียว รองรับไทยและอังกฤษ สลับได้

## เล่นยังไง

1. ใส่ชื่อเล่น แล้วกดสร้างห้อง จะได้รหัส 4 ตัว
2. ส่งรหัสให้เพื่อน เพื่อนใส่ชื่อ + รหัส แล้วกดเข้าห้อง (สูงสุด 8 คน)
3. หัวห้องเลือกหมวดเพลง ความยาก จำนวนข้อ แล้วกดเริ่ม
4. แต่ละข้อ ทุกคนได้ยินคลิปเดียวกันและมีเวลาตอบเท่ากัน ตอบถูก+ตอบเร็ว = คะแนนมาก
5. เฉลยพร้อมกันทั้งห้อง แล้วไปข้อถัดไป

เล่นคนเดียวก็ได้ — เป็นห้องที่มีคนเดียว ไม่ใช่โหมดแยก

## ความยาก

| ระดับ | เสียงดัง | ตอบได้ | ตัวคูณ | ตัวลวง |
|---|---|---|---|---|
| ง่าย | 15 วิ | 20 วิ | ×0.75 | ศิลปินต่างคนทั้งหมด |
| ปานกลาง | 10 วิ | 15 วิ | ×1 | ศิลปินต่างคนทั้งหมด |
| ยาก | 5 วิ | 10 วิ | ×1.5 | มีเพลงของศิลปินเดียวกันปนมา 1 |
| ยากมาก | 3 วิ | 8 วิ | ×2 | มีเพลงของศิลปินเดียวกันปนมา 2 |

เสียงหยุดก่อนหมดเวลาตอบเสมอ ช่วงเงียบหลังเพลงหยุดเป็นส่วนหนึ่งของความยาก

คะแนน = (100 + โบนัสเวลาสูงสุด 100) × ตัวคูณ โดย **server เป็นผู้จับเวลาและคิดคะแนน** เท่านั้น

## รันในเครื่อง

```bash
npm install && npm run dev
```

เปิด http://localhost:3004 สองแท็บเพื่อทดสอบเล่นด้วยกัน (เปลี่ยนพอร์ตด้วย `PORT=xxxx`)

| คำสั่ง | ทำอะไร |
|---|---|
| `npm run dev` | dev server พร้อม Socket.io |
| `npm run build` | build production |
| `npm start` | รัน production |
| `npm test` | เทสต์ |
| `npm run typecheck` | ตรวจ type |

ถ้า `npm install` ค้าง ให้ `export NODE_OPTIONS=--dns-result-order=ipv4first` ก่อน — ดู [DEPLOY.md](DEPLOY.md)

## โครงโค้ด

```
server.ts              custom Next server + Socket.io
src/shared/            ใช้ร่วมกันทั้ง server และ client
  types.ts             ชนิดข้อมูลหลัก
  difficulty.ts        ตารางความยาก
  scoring.ts           สูตรคะแนน (ฟังก์ชันบริสุทธิ์)
  protocol.ts          schema ของ socket event (zod)
  modes/               กติกาเกมที่ถอดเปลี่ยนได้ ตอนนี้มี quiz
src/server/
  rooms.ts             state machine ของห้องและแมตช์
  socket.ts            ต่อ socket event เข้ากับ rooms
  itunes.ts            ดึงเพลง + cache 24 ชม.
  catalog.ts           ประกอบคลังเพลงของแต่ละหมวด
src/client/            hook, audio engine, ระบบภาษา, component
src/data/seeds/        รายชื่อศิลปินของแต่ละหมวด
tests/                 เทสต์คะแนน ตัวลวง และลำดับเกม
```
